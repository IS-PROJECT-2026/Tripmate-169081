# TripMate

**TripMate** is a web-based travel planning application designed to help users discover destinations, plan trips, organize itineraries, manage packing lists, and keep track of their travel budgets in one place.

The application provides a simple and interactive way for users to organize their trips and personalize their travel planning experience.

---

##  Features

###  Destination Discovery

* Browse available travel destinations.
* Search destinations by name, country, or description.
* Filter destinations by category and budget.
* View detailed information about each destination.

###  Favourite Destinations

* Save destinations as favourites.
* View all saved destinations in the **My Favourite Destinations** section.
* Remove destinations from favourites.
* Favourite selections are stored using browser local storage.

###  Trip Planning

* Create a trip by entering:

  * Trip name
  * Destination
  * Start date
  * End date
* Automatically calculate trip duration.
* Save planned trips using browser local storage.
* Display the most recently planned trip.

###  Itinerary Management

* Automatically generate an itinerary based on the trip dates.
* Add activities to individual days.
* Edit activities.
* Delete activities.

###  Packing Checklist

* Add custom packing items.
* Mark items as packed.
* Edit packing items.
* Remove packing items.
* Track packing progress.

###  Trip Budget Calculator

* Enter estimated costs for:

  * Accommodation
  * Food
  * Transport
  * Activities
  * Other expenses
* Automatically calculate the total trip budget.
* Display the budget on the trip summary and dashboard.

###  Personal Travel Dashboard

The dashboard provides an overview of the user's travel planning activity, including:

* Number of favourite destinations.
* Number of planned trips.
* Current trip budget.
* Packing progress.
* Upcoming/next planned trip.

###  Responsive Design

TripMate is designed to work across:

* Desktop computers
* Tablets
* Mobile devices

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/IS-PROJECT-2026/Tripmate-169081.git
```

### 2. Open the project

Navigate into the project folder:

```bash
cd Tripmate-169081
```

### 3. Run the application

TripMate is a client-side web application, so no backend installation is required.

Open `index.html` in a web browser or use a local development server such as **VS Code Live Server**.

##  Data Storage

TripMate currently uses the browser's **Local Storage API** to save user-specific information.

The application stores information such as:

* Planned trips
* Favourite destinations

This allows saved information to remain available when the page is refreshed in the same browser.
